# @link-assistant/web-search

JavaScript implementation of the `web-search` library, CLI, and HTTP service.
It mirrors the Rust implementation in `../rust` with the same provider catalog,
categories, merge strategies, and discovery surface.

## Development

```bash
npm install
npm test
npm run check
node bin/web-search.js --list-providers
```

See the repository root `README.md` for the full cross-language API and provider
documentation.
